# Improving this guide

Report the app/version, the section that needs changing, and the steps you observed. Keep instructions short, name the exact UI controls, and separate confirmed behavior from suggestions.

For screenshots, use a demonstration configuration. Never include personal addon/manifest links, account IDs, keys, private lists or private server addresses. Keep public featured creators credited.

Before proposing an update:

1. Edit the Markdown source and rebuild with `python3 build.py`.
2. Open the HTML on a desktop and narrow screen; check navigation, tables and screenshots.
3. Verify Markdown image paths and instructions against the current interface.
4. Upload only the guide's curated files. Do not include `github-ready/`, ZIP files, unrelated output directories or account exports.
